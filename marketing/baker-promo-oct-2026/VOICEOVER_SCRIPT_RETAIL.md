## Production notes

* **Pace:** the script is a little long for 40 seconds, so the guide voice is sped up about 25% to fit. It sounds like a brisk retail read. For a normal pace, trim lines 3 and 4 slightly.
* **Guide voice:** it's good for timing and approvals, but a professional voice artist reading the same script will sound more natural.
* **Bahasa Melayu:** the full BM script is above, but there's no Malay synthetic voice available, so the BM version is text only for now.
* **Prices:** once the bundle price is confirmed, swap line 7's second sentence for: **"Buy both for just RM ___, and save RM ___!"** (BM: **"Beli kedua-duanya hanya RM ___, jimat RM ___!"**), then regenerate the audio.
